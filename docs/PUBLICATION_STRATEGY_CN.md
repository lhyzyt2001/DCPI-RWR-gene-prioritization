# 二区投稿定位建议

## 最可靠的主线

不要再把文章写成“提出了一个比所有基线更强的新深度模型”。现有结果不支持这一点。更可靠的主线是：**对癌症靶点网络扩散进行时间外、多癌种、中心性偏倚可解释的系统评估，并提出一个可调节性能—枢纽偏倚权衡的多视图扩散框架。**

## 创新性来自哪里

1. 使用 Open Targets 26.03 开发、26.06 新增证据验证，减少随机交叉验证的知识回流。
2. 在六个癌种重复同一设计，明确可迁移性而不是只报告 LUAD 单数据集。
3. 同时报告全排序 AUPRC 与固定预算 Top-100，因为后者更接近实验筛选场景。
4. 把 STRING 度数偏倚设为主要研究对象，量化减少枢纽后的性能代价。
5. 用度数匹配种子零模型、路径分量条件置换和留一癌种迁移排除简单的拓扑解释。
6. 锁定候选后才做 TCGA、GSE68465、CPTAC 表征，避免用外部结果反向挑选候选。

## 结果是否足以支撑二区

这套结果比原来的“GNN 弱于 RWR、却突出 GNN”明显更稳健，也更有方法学深度，但仍不能保证二区录用。最有价值的结果是 6/6 癌种 Top-100 枢纽比例下降，同时总新增证据命中数从 34 增至 44；但命中增益 P=0.143，不能写成显著提高。全排序 AUPRC 没有改善，CRC 还显著下降，因此标题和摘要必须突出“trade-off”“bias-aware evaluation”“time-separated validation”，不能突出“superior performance”。

## 期刊风险控制

- 优先考虑计算生物信息学、网络医学、方法评估方向的二区期刊。
- 不建议 BMC Medicine；其临床与机制证据要求远高于当前研究。
- BMC Genomics 可以尝试，但摘要必须降低治疗靶点和临床转化措辞。
- 若编辑要求明确生物机制，现有纯计算结果仍可能不足；这不是通过语言修改就能完全解决的。
