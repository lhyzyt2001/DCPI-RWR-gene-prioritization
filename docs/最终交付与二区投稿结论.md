# 最终交付与二区投稿结论

## 已完成的核心改进

本版本围绕三个预先确定的优先事项完成了实验补充：

1. 使用 Open Targets 26.03 与 26.06 构建历史—未来时间外验证，并在 LUAD、BRCA、CRC、PRAD、MEL 和 OV 六个癌种中重复；
2. 补全网络中心性偏倚审计，包括 degree 分层、精确/近似 degree 匹配、条件置换、删除高连接节点及 degree 区间校准与 Top-K 恢复；
3. 在完全相同的外层划分下，对 APPNP、GCNII 和 GATv2 进行多优化随机种子比较，并使用按基因聚类的 bootstrap 与 RWR 比较。

此外，本版本保留了 PU 学习敏感性、候选基因重新排名、TCGA/GSE68465/CPTAC 外部表征以及 primary 与 degree-residualized GSEA。所有强基线和阴性结果均被保留，没有为了突出新模型而删除 RWR 或 degree 基线。

## 关键结果

- Open Targets 26.06 LUAD 当前端点的 15 个外层折中，RWR、LightGBM 和 XGBoost 的平均 AUPRC 分别为 0.5542、0.5364 和 0.5338。按基因聚类 bootstrap 后，LightGBM−RWR 与 XGBoost−RWR 的 95% 置信区间均跨越 0。
- 在当前端点的 degree 匹配分析中，LightGBM−RWR 的中位 AUPRC 差为 0.0086，95% CI 为 −0.0016 至 0.0187，双侧 P=0.086；证据方向为正，但不足以支持稳健优越性。
- 26.03→26.06 固定特征时间外验证仅产生 14 个 LUAD 新阳性，RWR仍为表现最好的方法；该结果应被解释为低事件数的探索性时间外验证。
- 六癌种随机效应汇总未显示 LightGBM 或 XGBoost 相对 RWR 的稳定增益。
- 统一多随机种子比较中，APPNP、GCNII 和 GATv2 的平均 AUPRC 分别约为 0.4001、0.4073 和 0.3605，均显著低于 RWR 的 0.4390；三种深度模型的按基因聚类 bootstrap 置信区间均完全低于 0。
- 历史端点的精确 degree 匹配可观察到树模型相对 RWR 的增益，但条件置换显示 RWR 与 degree 仍是主要信息来源，且候选集高度富集于网络枢纽。因此，该增益不能被解释为拓扑无关的疾病机制发现。
- 新候选集的 TCGA、GSE68465 与 CPTAC 表征提供了表达层面的支持，但经多重校正的生存关联不足；DepMap 未因数据版本和候选集改变而被不恰当地复用。

## 正确性判断

当前结果在统计流程和内部一致性方面是可解释且可复核的：外层测试标签未进入模型拟合或 RWR 种子构建，深度模型使用相同划分和统一评估，重复预测通过按基因聚类 bootstrap 处理，图件同时提供高分辨率 PNG 与矢量 PDF。最终 `QA_REPORT.json` 用于记录自动化完整性与泄漏检查。

“深度模型或树模型没有稳定超过 RWR”不是实验错误，而是本数据结构下的重要阴性发现。网络传播与标签端点都受到连接度和既有研究强度影响，简单的 RWR 更符合该信号结构，因此优于参数更多的模型具有合理性。

## 二区投稿定位

这套结果不适合再包装成“提出性能显著优于基线的新算法”。更可靠的方向是：

> 对临床证据型癌症基因优先级任务进行时间外、跨癌种、PU 不确定性和网络中心性偏倚审计，并说明复杂机器学习与深度图模型何时不能稳定优于简单网络传播。

该定位具备方法学完整性和可发表价值，可考虑 BMC Genomics 或计算生物信息学方向期刊，但不能保证中科院二区录用。最主要的剩余局限是：真正冻结于历史时点的全部特征快照仍有限；时间外 LUAD 新阳性仅 14 个；候选基因仍受网络拓扑影响；新的候选集缺少与其完全对应的 DepMap/实验功能验证。

若继续增强，优先顺序应为：获得可核验的历史特征快照或独立疾病基因资源；对新候选集重新开展版本匹配的功能验证；最后再考虑湿实验。不要通过删除强基线、选择性报告随机种子或改写阴性结果来制造算法优势。
