# DCPI-RWR v1.0.0

This is the first public release of the degree-conditioned pathway-integrated random walk with restart framework.

## Naming and packaging

- uses the public package identity `DCPI-RWR-release-v1.0.0`;
- identifies boosted comparators as `LightGBM + RWR/features` and `XGBoost + RWR/features`;
- renames the fixed-candidate characterization entry point to `code/09_characterize_dcpi_candidates.py`;
- retains earlier PU-learning and multiview-GCN analyses only as clearly labelled provenance material.
- includes the final five manuscript figures, the Figure 1 generation script, pinned dependencies, citation metadata and a complete SHA-256 manifest;
- documents the cross-release boundary, negative results and centrality-bias interpretation limits explicitly.

No input, split, fitted prediction, performance value, candidate list or statistical conclusion was changed.
